01 / THE CHALLENGE

What this project does.

Recognising a drone component is one step. Helping a person understand that component is another. This project brings visual detection and information retrieval into one two-phase assistant.

A two-phase intelligent system combining computer vision and natural language processing to identify and query drone components.

02 / THE APPROACH

How it works.

A fine-tuned YOLO-based model detects and classifies components in images and video. A retrieval-augmented generation pipeline supports interactive questions about detected parts.

01DetectYOLO-based vision+

The fine-tuned model detects and classifies drone components from images and video.

02RetrieveRelevant information+

The retrieval stage brings relevant component information into the answering pipeline.

03ExplainLanguage assistant+

The RAG pipeline supports interactive questions about the detected drone parts.
